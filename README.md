# Jumcent Properties Website

Official website for **Jumcent Properties** (`https://jumcentproperties.co.uk`) — showcasing fully furnished short-let and contractor accommodation across the United Kingdom and select international locations.

## Portfolio

- **Sky-Glover House** — 2-Bedroom Terraced Home in Crewe, Cheshire East, UK (`property-sky-glover.html`)
- **Campbell Place** — 4-Bedroom Contractor & Family Home in Stoke-on-Trent, UK (`property-campbell.html`)
- **Fenham Place** — 3-Bedroom Serviced Home in Newcastle upon Tyne, UK (`property-fenham.html`)
- **SkyHouse Shortlet Apartment** — 1-Bedroom Serviced Apartment in Oba-Ile, Akure, Nigeria (`property-skyhouse.html`)

## Key Features

- **WCAG 2.2 AA Accessible Dark Design System** (`styles.css`)
- **UK & International Portfolio Filter** (`properties.html`)
- **Keyboard, Touch-Swipe & Fullscreen Photo Lightbox** (`script.js`)
- **UK PECR / GDPR Consent-Gated Google Analytics** (`privacy.html`, `script.js`)
- **Schema.org Structured Data (`LodgingBusiness`, `CollectionPage`, `FAQPage`, `BreadcrumbList`)**
- **Security Headers Ready** (`_headers` for Cloudflare Pages / Netlify)
